wasp read alignment in the browser

Choose your files and click 'Run Analysis', no data leaves the browser.
The reference can have multiple entries (FASTA, GenBank or FASTQ, optionally gzipped). Existing coordinate-sorted BAM files (select their .bai index too) skip alignment; the reference is then optional.
Each FASTQ file is a separate sample; R1/R2 pairs (e.g. x_R1.fastq.gz + x_R2.fastq.gz) are aligned together as paired-end.
